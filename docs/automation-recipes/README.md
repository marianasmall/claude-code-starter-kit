# Automation Recipes

Practical, follow-along guides for everyday automations you can build with Claude Code —
written for people setting up their first assistant workflows, not for developers.
Each recipe is one card: what it does, what you need, the steps, and the prompt to start from.

to connect, or recipe 11 the next time a confusing letter lands in your mailbox.

*Credit where due: the idea list for the first ten recipes was sparked by a use-case

here were written from scratch for this series.*

## How these differ from the primers

The [primers](../) explain *features* (plan mode, worktrees, output styles).
Recipes assemble features into a *finished daily habit* — each one ends with something
that runs on a schedule or a single phrase, not just something you understand.

## Format (every recipe follows it)

1. **What you get** — the output, shown before any setup
2. **What you need** — connected tools, in plain language, with links to the relevant primer
3. **Build it** — numbered steps, copy-paste prompts included
4. **Make it stick** — scheduling it (or the phrase that triggers it)
5. **Variations** — how to bend it to your situation
